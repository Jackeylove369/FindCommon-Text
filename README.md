# 寻找两个链表的第一个公共结点 (FindCommon)

## 项目简介
本项目是一个基于 C 语言的链表算法学习程序，主要实现了**带头结点的单链表**基本操作，并在此基础上完成了 408 考研数据结构的高频考点算法：**寻找两个链表的第一个公共结点（Y 字形链表）**。

程序包含了完整的测试用例，涵盖了“有公共结点”和“无公共结点”两种情况，并演示了正确的链表内存释放流程。

## 算法思想 (核心考点)

本程序采用**“长度对齐，同步遍历”**的双指针法，时间复杂度最优。

1. **求长度**：分别遍历链表 A 和链表 B，计算出两个链表的长度 `lenA` 和 `lenB`。
2. **对齐起点**：计算长度差 `diff = |lenA - lenB|`。让较长链表的指针先向前移动 `diff` 步。此时，两个指针距离链表尾部的距离相同。
3. **同步前进**：两个指针同时向后遍历，判断 `p == q`（即物理地址相同）。
4. **返回结果**：如果 `p == q` 且不为 NULL，则找到第一个公共结点；如果遍历到 NULL 仍未相遇，则说明无公共结点。

> **注意**：公共结点指的是内存中**同一个结点**（物理地址相同），而不是数据域 `data` 相同的结点。所以判断条件是 `p == q`，而不是 `p->data == q->data`。

## 复杂度分析

* **时间复杂度**：`O(lenA + lenB)`。最多遍历两个链表各一次。
* **空间复杂度**：`O(1)`。只使用了常数个辅助指针变量，未开辟额外的辅助空间。

## 项目结构

* `InitList()`：初始化带头结点的空链表。
* `Insert(L, x)`：尾插法插入元素。
* `Print(L)`：遍历并打印链表（格式：`1->2->3->NULL`）。
* `Length(L)`：求链表长度（不包含头结点）。
* `FindCommon(A, B)`：**核心算法**，寻找第一个公共结点。
* `DestroyList(L)`：销毁链表，释放所有申请的内存。
* `main()`：包含两个测试用例，验证算法的正确性。

## 测试用例说明

程序在 `main` 函数中构建了两个测试用例：

### 用例 1：有公共结点（Y 字形）
* 公共部分：`6 -> 7 -> 8`
* 链表 A：`1 -> 2 -> 3 -> 6 -> 7 -> 8`
* 链表 B：`4 -> 5 -> 6 -> 7 -> 8`
* **预期输出**：第一个公共结点 = 6

### 用例 2：无公共结点
* 链表 C：`1 -> 2`
* 链表 D：`9 -> 8 -> 7`
* **预期输出**：无公共结点（返回 NULL）

### 内存安全提示
在 `main` 函数中，用例 1 的链表 A 和链表 B 共享了 `common` 链表的结点。因此在释放内存时，代码先执行了 `tailA->next = NULL;` 和 `tailB->next = NULL;`，断开了 A 和 B 对公共部分的引用，然后再调用 `DestroyList`。这是一种严谨的防止**重复释放（Double Free）**导致程序崩溃的操作。
